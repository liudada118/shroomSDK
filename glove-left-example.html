将 glove-left-example.html 放在解压后的 SDK 根目录，与 web/ 同级。执行 node start.mjs --no-open，打开 http://localhost:5178/glove-left-example.html；若终端显示了其他端口，请替换地址中的端口。使用支持 Web Serial 的浏览器，通过 localhost 或 HTTPS 访问。

当前示例使用 Windows 的驱动与端口提示；其他系统可在产品接入页面选择实际系统后重新生成。

1. 安装驱动，确认系统串口

CH34x 设备未安装驱动时，系统可能无法识别串口。先安装对应驱动，重新插拔设备，再核对系统中的端口。

Windows 驱动（EXE） · macOS 驱动（ZIP）

Windows：在设备管理器的“端口（COM 和 LPT）”中确认设备。 关闭占用端口的上位机或其他采集程序。

当前示例配置：左手触觉手套。这来自你选择的配置，尚未识别实物；请核对左右手，手侧错误仍可能收到数据。

2. 激活 SDK 授权

SDK 使用独立产品密钥，许可不限制传感器型号；仍需满足有效期、电脑名额与已适配的硬件协议。离线码使用 SDK 默认信任的公钥验证。

示例不持久保存密钥，激活完成后会清空输入框。名额已满、换机或密钥未获取时，请联系发放密钥的管理员。
