Shroom SDK · 最小示例

连接串口 → 拿到数据 → 画成热力图。整个页面的逻辑就是下面那段 script。

完整快速接入：WS → 产品展示 → 标签录制 → 下载

先安装串口驱动

缺少匹配的驱动时，系统可能无法识别设备，本页也无法读取该串口。请在连接设备的这台电脑安装驱动。

Windows 驱动 · EXE macOS 驱动 · ZIP（解压后按说明安装）
  1. 连接列表没有串口时，先安装对应系统驱动。
  2. 安装后重插设备，并重启浏览器。
  3. 重新点击“连接设备”，查看串口选择列表；仍不可见时检查 USB 数据线与系统串口识别情况。

你是双击打开这个文件的（file://）。模拟数据能正常跑，但连不了真实设备—— 浏览器规定串口只在 https 或 localhost 下开放，这条绕不过去。 要连设备：回到 SDK 根目录，双击 start-demo.bat（macOS / Linux 是 sh start.sh）。

尚未激活；模拟数据可直接使用

真实设备需要有效 SDK 产品密钥，SDK 授权不限制设备型号；协议与解码配置仍需与设备匹配。限定电脑数量的密钥需联网。密钥只在本次页面内使用。
