快速接入：从产品连接到数据下载

后端负责串口取数和文件录制；本页连接 WS，显示产品数据并控制采集。

连接产品前，先安装串口驱动

驱动安装在连接真实设备、运行 Node.js 采集服务的电脑上。缺少匹配驱动时，系统可能找不到串口，后端也无法取数；仅查看 WS 数据的电脑无需为此安装驱动。

Windows 驱动 · EXE macOS 驱动 · ZIP（解压后按说明安装）

找不到串口 → 安装对应系统驱动 → 重插设备并重启 Node.js 采集程序 → 重新查询端口，确认可见后再连接产品。

2. 数据采集

开始与停止都在这里操作；下载在下方独立区域。

尚未查询服务端录制状态
断开本页不会停止后端采集。重新连接可确认状态并继续操作。

3. 下载采集数据

选择对应记录下载，SDK 使用该记录的 ID 获取数据；下载不会开始或停止采集。停止并完成 SQLite 入库后即可导出，CSV 用于分析，JSONL 保留完整帧。采集库保存在 Node 服务端，不依赖本页是否保持打开。
